# League of Legends Stuff Randomizer 🎰

A chaotic League of Legends challenge generator built for GitHub Pages.

## Modes

- **Easy** — random champion, random role, Flash + one random Summoner Spell.
- **Hard** — random champion, random role, two random Summoner Spells, two random items.
- **Nightmare** — random champion, random role, two random Summoner Spells, full six-item random build.

## Features

- Live Riot Data Dragon data (French locale)
- Seeded challenges: share the exact same roll with friends
- Champion, role, Summoner Spell and item icons
- Responsive mobile/desktop UI
- No backend, no API key
- Ready for GitHub Pages
